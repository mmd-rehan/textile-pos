# Feature Flags

## Purpose

Feature flags allow incomplete or future features to remain disabled.

## Potential Flags

- enableWholesale
- enableCreditLedger
- enableTax
- enableSupplierPayments
- enablePurchaseReturns
- enableCustomerNotifications
- enableMultiBranch, future only

## Rule

Feature flags should not bypass backend permissions.

# Inventory Validation Rules

## Length Validation

- Original length must be greater than zero.
- Remaining length cannot be greater than original length unless created by authorized adjustment.
- Sale deduction cannot exceed remaining length.
- Actual cut length must be greater than zero for fabric sale lines.

## Unit Validation

- Accepted units: YARD, METER.
- Backend must convert to base unit before persistence.
- Unknown units must be rejected.

## Barcode Validation

- Barcode must be unique among active rolls/products.
- Barcode should be generated by the system unless manual entry is explicitly enabled.

## Product Validation

- Product code should be unique.
- Product type is required.
- Variable fabric products require measurement unit support.

## Batch Validation

- Batch number is required for roll-based fabric.
- Dye lot may be optional but should be stored when available.

## Reason Validation

Reason is required for:

- Manual adjustment
- Reconciliation difference
- Roll damage
- Wastage correction
- Negative stock override, if ever implemented

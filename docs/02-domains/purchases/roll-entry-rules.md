# Roll Entry Rules

## Rules

- Each roll requires product, batch, original length, and barcode.
- Roll length must be greater than zero.
- Roll barcode must be unique.
- Rolls entered from purchase should reference purchase line.
- Each roll may have different length.
- Current remaining length starts equal to original length.

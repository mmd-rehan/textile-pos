# Purchase UI Behavior

## Screens

- Supplier list
- Supplier detail
- Purchase list
- Purchase entry
- Roll entry grid
- Batch selector/creator
- Barcode print after purchase

## UI Rules

- Purchase form should allow creating supplier/product/batch without leaving workflow where practical.
- Roll entry should support quick input of multiple roll lengths.
- Show generated roll codes before saving if possible.
- After save, allow barcode print/download.

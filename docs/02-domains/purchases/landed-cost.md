# Landed Cost

## Definition

Landed cost is actual cost including purchase, transport, taxes, labor, and other expenses.

## Current Status

Landed cost is identified in terminology but allocation rules are not confirmed.

## Recommended Pending Design

- Store landed cost components separately.
- Allocate costs to rolls only after business confirms allocation method.
- Keep original purchase price and allocated landed cost visible separately.

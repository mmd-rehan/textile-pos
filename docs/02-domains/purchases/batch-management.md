# Batch Management

## Purpose

Batch/dye lot tracking is critical because fabric from different batches may have slight color variation.

## Batch Data

- Product
- Batch number
- Supplier batch number, optional
- Dye lot, optional
- Color/design metadata, optional
- Purchase date

## Rules

- Roll-based fabric should have batch assigned.
- POS should show batch when selecting rolls.
- Batch mismatch warnings should be possible during sales.

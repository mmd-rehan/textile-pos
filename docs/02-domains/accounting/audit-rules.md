# Accounting Audit Rules

## Rules

- Financial records should not be silently modified.
- Corrections must create adjustment or reversal entries.
- Sensitive actions require permission.
- Reason is required for manual adjustments.
- Audit log should capture actor, timestamp, before/after values, and reason.

## Sensitive Actions

- Delete/cancel invoice
- Refund
- Ledger adjustment
- Expense deletion
- Supplier payment cancellation
- Customer payment cancellation

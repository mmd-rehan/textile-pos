# Ledger System

## Ledger Types

- Customer ledger
- Supplier ledger
- Cash ledger
- Expense ledger
- General ledger, pending accounting depth confirmation

## Rules

- Ledger entries should be immutable.
- Adjustments must create new entries.
- Source document should be linked.
- Running balance can be shown in UI.

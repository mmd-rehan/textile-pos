# Expense Management

## Purpose

Expense management records shop expenses such as rent, salaries, transport, utilities, and miscellaneous costs.

## Candidate Fields

- Expense date
- Category
- Amount
- Payment method
- Description
- Attachment, pending confirmation
- Created by

## Rules

- Expense records must be auditable.
- Deletion should be restricted.
- Corrections should use edit history or adjustment depending on accounting depth.

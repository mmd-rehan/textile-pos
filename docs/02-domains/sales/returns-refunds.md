# Returns and Refunds

## Purpose

Returns and refunds must reverse or adjust sales, customer balances, payments, and inventory movements in a traceable way.

## Return Types

- Full invoice return
- Partial line return
- Quantity-based return for fixed products
- Fabric return, pending business confirmation

## Important Textile Concern

Fabric that has been cut may not be returnable in many shops. This business policy is not confirmed. Until confirmed, fabric returns should be marked as pending decision.

## Rules If Returns Are Enabled

- Return must reference original invoice and line item.
- Return must create inventory movement if stock is accepted back.
- Returned fabric should not automatically return to original roll unless physically valid.
- Refund must create financial/ledger entry.
- Reason is required.
- Approval may be required.

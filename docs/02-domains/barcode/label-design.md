# Label Design

## Label Content Options

Roll label may include:

- Barcode
- Roll code
- Product code/name
- Batch/dye lot
- Original length
- Price, pending confirmation

## Design Rules

- Barcode must be large enough to scan.
- Important text should be readable after printing.
- Keep label simple for small printers.

## Pending Confirmation

- Label size.
- Printer paper type.
- Whether price should be printed.

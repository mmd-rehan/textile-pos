# Barcode Printing Rules

## Browser Printing

Version 1 should support browser printing. Native printer drivers are not part of scope.

## Print Events

- Print after roll purchase entry.
- Reprint from roll detail.
- Print product labels if needed.

## Rules

- Failed print should not roll back saved purchase.
- User should be able to reprint barcode.
- Label should be readable and scanner-friendly.

## Pending Confirmation

- Label paper size.
- Label layout.
- Whether price appears on labels.

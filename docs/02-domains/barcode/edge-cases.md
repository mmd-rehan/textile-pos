# Barcode Edge Cases

## Edge Cases

- Unknown barcode.
- Duplicate barcode.
- Damaged label cannot scan.
- Product barcode scanned but multiple rolls exist.
- Roll barcode scanned for finished roll.
- Scanner sends incomplete input.
- Printer fails after purchase save.

## Rules

- Unknown barcode shows error.
- Duplicate barcode must be blocked.
- Finished roll cannot be sold.
- Reprint should be available.

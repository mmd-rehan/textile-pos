# Dashboard Metrics

## Dashboard Metrics

### Inventory

- Total stock
- Low stock rolls
- Remnants
- Dead stock
- Fast-moving products

### Sales

- Today sales
- Monthly sales
- Invoice count
- Top products

### Finance

- Cash collected
- Credit outstanding
- Expenses
- Profit estimate, pending costing method

### Loss Control

- Wastage quantity
- Shrinkage quantity
- Salesman wastage ranking

## Performance Target

Dashboard loading target is under 2 seconds.

1. Current stock report matches roll totals.
2. Sales report excludes cancelled invoices.
3. Credit report matches customer ledger balances.

5. Remnant report shows active remnant items.
6. Dashboard loads within target on seeded data.
7. Unauthorized role cannot access financial reports.
8. Date filters return correct boundary results.
9. Export matches visible filtered data, if exports are enabled.
